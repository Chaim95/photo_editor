# סטודיו מגנטים 🧲

כלי עבודה מקצועי לצלמי מגנטים באירועים: טוענים מסגרת ותמונות, בוחרים מה להדפיס ובכמה עותקים, והמערכת משבצת הכל על דפי A4 בצורה החסכונית ביותר ומדפיסה.

הכל רץ **מקומית בדפדפן** – אין העלאה לרשת, אין שרת, ועובד גם בלי אינטרנט באולם.

## הפעלה

אין צורך בהתקנה. אפשר פשוט לפתוח את `index.html` בדפדפן (Chrome / Edge מומלצים).

להפעלה דרך שרת מקומי (מאפשר גם עבודה אופליין מלאה כאפליקציה):

```bash
python3 -m http.server 8080
```

ואז לגלוש ל־`http://localhost:8080`.

## תהליך העבודה

1. **מסגרת** – טוענים קובץ PNG עם אזור שקוף. אפשר לטעון גם גרסה אופקית: כל תמונה תקבל אוטומטית את המסגרת המתאימה לכיוון שלה. המסגרות נשמרות במחשב לפעם הבאה.
2. **תמונות** – גוררים קבצים או תיקייה שלמה מהכרטיס (או "הוסף תיקייה"). קבצי RAW, קבצי מערכת (`._`) וכפולים מסוננים אוטומטית.
3. **התאמה** – התמונה ממלאת את המסגרת בלי עיוות (מילוי מרכזי). כשכיוון התמונה לא תואם למסגרת היא מסומנת "כיוון שונה" ומופיעה בסינון "לבדיקה". בעורך (לחיצה כפולה / E) אפשר להזיז, לעשות זום, לסובב, לבחור "תמונה מלאה" (ללא חיתוך, עם רקע מטושטש) או מסגרת אחרת.
4. **בחירה וכמויות** – לחיצה על תמונה בוחרת אותה, `+`/`−` לעותקים, `1`–`9` לכמות מדויקת, Shift+לחיצה לטווח, Ctrl+A לבחירת הכל.
5. **שיבוץ** – בוחרים גודל מגנט (5×7.5, 6×9, 6.5×9, 7×10, 9×13, 10×15 או מותאם אישית) או כמות מגנטים בדף. שיבוץ משולב מנצל שטח שנשאר בדף עם מגנטים מסובבים (לדוגמה 11 במקום 10 מגנטים של 5×7.5).
6. **ניצול דפים בזמן אמת** – שורת הסטטוס מציגה כמה מגנטים ודפים, ואם הדף האחרון חלקי: "דף אחרון: 5 מתוך 9 – אפשר להוסיף עוד 4".
7. **תצוגה מקדימה והדפסה** – כל דף A4 מוצג בדיוק כפי שיודפס; המערכת מכינה קבצים ברזולוציית הדפסה (200/300/400 DPI) ורק לאחר אישור פותחת את חלון ההדפסה. הפלט מכיל אך ורק את דפי ה־A4, עם מעבר עמוד מדויק. אחרי ההדפסה התמונות מסומנות "הודפסה".

### הגדרות מומלצות בחלון ההדפסה
נייר A4 · שוליים: ללא · קנה מידה 100% · "גרפיקת רקע" מופעלת.

## ארכיטקטורה

| קובץ | תפקיד |
|---|---|
| `js/engine.js` | פענוח תמונות (כולל כיוון EXIF), הרכבת תמונה+מסגרת, ומאגר Web Workers עם OffscreenCanvas כדי שהממשק לא ייתקע |
| `js/layout.js` | אלגוריתם שיבוץ על A4 (גריד בשני הכיוונים + שיבוץ משולב), חישוב גודל לפי כמות |
| `js/app.js` | מצב האפליקציה, ייבוא, גלריה, בחירה, סטטיסטיקות |
| `js/editor.js` | עורך לתמונה בודדת (גרירה, זום, צביטה, סיבוב, התאמה) |
| `js/print.js` | תצוגה מקדימה, הכנת קבצים ברזולוציה מלאה והדפסה |
| `js/store.js` | שמירת הגדרות (localStorage) ומסגרות (IndexedDB) |

**ניהול זיכרון:** מכל קובץ מקור נשמרת רק תצוגה מוקטנת דחוסה; הקובץ המקורי נקרא מחדש מהדיסק רק כשצריך רזולוציה מלאה (עורך / הדפסה), ותמונות הדפסה נשמרות במטמון רק עבור העבודה הנוכחית.
